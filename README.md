## Project summary (human-written)
This project implements a small reflected XSS scanner in Python that:
- Injects context-aware payloads (attribute-name, attribute-value, text-node, script).
- Tests GET and POST endpoints.
- Detects reflections by searching for the exact injected payload in raw responses,
  and classifies the reflection context using a combination of raw string search,
  JSON inspection, and BeautifulSoup-based HTML parsing.
- Produces an HTML report summarizing findings.

This submission is prepared for the assignment located at:
`/mnt/data/Security assignment.pdf`

## Assumptions
- The target URL is reachable from the environment where the scanner runs.
- Simple substring matching is acceptable for reflection detection for this assignment.
- The scanner is intended for authorized testing only (penetration test with permission).
- The scanner is lightweight and designed to be demonstrative — not a full replacement
  for professional tools like Burp Suite.

## How PayloadGenerator decides payloads
- A `base_marker` string (e.g., `XSSTOKEN_<RND>`) is created once per scan instance.
- For each injection context the generator creates a unique payload by appending a random suffix.
  - `attr_name`: `XSSTOKEN_XXX=1`
  - `attr_value`: `"XSSTOKEN_XXX"`
  - `text`: `XSSTOKEN_XXX<img src=x onerror=alert(1)>`
  - `script`: `');console.log('XSSTOKEN_XXX');//`
- The scanner searches for the exact payload (including suffix) in responses; this avoids cache/cross-test collisions.

## Reflection detection approach
1. Send a request with a single parameter containing the exact payload.
2. Inspect the raw response for an exact match of the payload.
3. Attempt to parse the response as JSON: if payload is in the serialized JSON, mark `json`.
4. Parse as HTML with BeautifulSoup and inspect tags, attributes, script contents and comments
   to classify contexts: `attribute-name`, `attribute-value`, `text-node`, `script`, `comment`.
5. Produce a simple HTML report with parameter, payload, contexts, and a short snippet.

## How to run
1. Create Python environment:
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   ```
2. Example scan (preserve original query):
   ```bash
   python reflected_xss_scanner_v3.py \
     --url "https://crash-stats.allizom.org/search/results/?date=%3E%3D2025-11-15T12%3A17%3A00.000Z&date=%3C2025-11-22T12%3A17%3A00.000Z&_facets=signature&page=1&_sort=-date&_columns=date&_columns=signature&_columns=product&_columns=version&_columns=build_id&_columns=platform&oapm4tz734=1" \
     --params date,_facets,page,_sort,_columns,oapm4tz734 \
     --preserve-query
   ```
3. Example scan against a known reflector (for demo):
   ```bash
   python reflected_xss_scanner_v3.py --url "https://httpbin.org/get?test=1" --params test --preserve-query
   ```
4. Output: `report_v3.html` will be written to the working directory.

## What works / What remains
- Works:
  - Independent parameter injection (does not zero out other params).
  - Exact-payload detection and classification for HTML and JSON responses.
  - GET and template-based POST requests (using `--post-data` with `__INJECT__`).
  - Multi-threaded testing of provided parameters.
- Partially done / future improvements:
  - More aggressive filter-bypass payloads.
  - Detection of reflections inside encoded/obfuscated JS (requires dynamic execution).
  - More comprehensive payload library (e.g., event-attribute variations).
  - Optional integration with authenticated sessions (this can be added via headers/cookies).
